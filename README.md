# إصدارات سطح المكتب لنظام إدارة المدارس (Windows x64)

يستضيف هذا المستودع ملفات التثبيت والتشغيل الرسمية لتطبيق سطح المدارس على نظام ويندوز فقط (دون أي شيفرة مصدرية).

- **الروابط الثابتة (`latest-<slug>`):** تحافظ على نفس الرابط الدائم وتتحدّث تلقائياً مع كل إصدار جديد.
- **النسخ المؤرّخة (`<slug>-v<version>-<timestamp>`):** أرشيف دائم لكل إصدار محدّد برقم النسخة والوقت.
